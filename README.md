# Maison Soleil

[Maison soleil screenshot](./assets/images/maison-solei-screnshot.webp)

Maison Soleil is a website that displays a booking confirmation page for a fictional hotel. It is one of the FrontendMentor.io challenges.

It is created using vanilla HTML, CSS and JavaScript; no frameworks or libraries.

To use it simply clone this repo and start a simple web server and serve the index.html file, or just open the index.html file with any browser.
